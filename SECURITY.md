# Security

Baton runs locally, has no network code, and never reads sign-in credentials or tokens. If you find a way it could expose account data, lose user files or be used against Anthropic’s terms, please report it privately through [GitHub Security Advisories](https://github.com/trukhinyuri/Baton/security/advisories/new) rather than a public issue. I aim to respond within a week.

Security fixes go into the latest release. [docs/SECURITY-MODEL.md](docs/SECURITY-MODEL.md) describes what the app can reach and what it never does.
